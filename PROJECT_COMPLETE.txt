🔧 ARCHITECTURE OVERVIEW
═════════════════════════════════════════════════════════════════════════════

   ↓

   ↓

   ↓

   ↓
[DETECTOR]    - Z-score anomaly detection
   ↓
[ALERTING]    - Format and output alerts

Each component runs independently in goroutines
Channel-based communication for thread-safe coordination

⚙️ CONFIGURATION OPTIONS
═════════════════════════════════════════════════════════════════════════════

-log string              Path to audit log
                         (default: "/var/log/audit/audit.log")

-window duration         Aggregation window size
                         (default: 10s)

-baseline int            Number of windows for baseline learning
                         (default: 30)

-threshold float         Z-score threshold for anomaly detection
                         (default: 2.5)

-poll duration           Poll interval for log file
                         (default: 500ms)

-verbose                 Enable verbose output for debugging
                         (default: false)
